# 算法小记

## 数组
数组是一种线性表结构，它用一组连续的内存空间，来存储一组具有相同类型的数据  
**1.线性表** 
1. 线性表，每个线性表上的数据最多只有前和后两个方向，数组、链表、队列、栈都是线性表结构；
2. 非线性表，不是简单的前后关系，二叉树、堆、图等；  
3. 数组需要提前确定大小，在java里面可以使用ArrayList进行动态扩容

**2.连续的内存空间和相同类型的数据**
1. 高效的访问元素，低效的删除、插入数据； 
2. 需要访问某个元素时，通过内存地址来访问，比如
```js
a[i]_address = base_address + i * data_type_size
```
3. 数组中最好是插入末尾O(1),最坏是插入头部O(n),插入第二个需要移动n-1个元素，插入第二个需要移动n-2个元素，(n+n-1+n-2+...+1)/n = (n+1)/2 = O(n),所以平均时间复杂度是O(n)
4. 数组中删除头部O(n),删除末尾O(1),删除中间O(n),所以平均时间复杂度是O(n)

**为什么数组下标为0**
如果是从1开始计数，那么计算内存地址就会变为:arrow_down:，每次访问数组都会多一次减法运算
```js
a[i]_address = base_address + (i-1) * data_type_size
```

## 链表
链表不需要连续的内存空间，它通过指针将一组零散的内存块串联起来使用，常见的链表结构：  
1. 单向链表
2. 双向链表
3. 循环链表 

**特点**
1. 链表的插入和删除非常高效，因为不需要保持内存的连续性，时间复杂度为O(1)
2. 链表的查询时间复杂度为O(n)
3. 双向链表因为有前驱指针，所以查询的时间复杂度为O(1)，但是会比单链表多存储一个指针；
4. 对链表进行频繁的删除、插入操作还会导致频繁的内存申请和释放，容易造成内存碎片；
