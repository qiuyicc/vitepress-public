# 入站配置与导出节点

目标：在 3x-ui 建一条 **VLESS + RAW(TCP) + Reality** 入站，导出给 v2rayN。

## 1. 添加入站（推荐稳定组合）

本次踩坑：一开始用 **XHTTP + mlkem** 等复杂组合，客户端延迟 **-1**、连不上。  
改成下面组合后延迟约 **220ms** 可通。

### 基础

- 备注：如 `新加坡`
- 协议：**VLESS**
- 端口：自定义高位端口（例 `31934`），并 `ufw allow 该端口/tcp`

### 传输

- 传输：**RAW**（新版面板里 RAW ≈ 以前的 TCP）
- Proxy Protocol / HTTP 混淆 / Sockopt：先全关

> 下拉里没有单独的 “TCP”，不要误选 mKCP / XHTTP（初学）。

### 安全（Reality）

| 字段 | 填写示例 |
|------|----------|
| 安全 | Reality |
| 目标 Target | `www.microsoft.com:443`（**必须带端口**） |
| SNI | `www.microsoft.com`（与目标域名一致） |
| 公钥/私钥 | 用面板生成 |
| ShortId 等 | 按面板默认或生成 |

可用「扫描 / 查找目标」辅助，但初学固定微软/苹果一类站点即可。

### 嗅探

- 启用：开
- 协议勾选：`http`、`tls`、`quic`（有则勾）
- 「仅元数据 / 仅路由」：先关
- 有「目标覆盖」则打开

保存后确认 Xray 在跑：`x-ui` 菜单看 Xray state，或 `x-ui status`。

## 2. 添加客户端

入站建好后，若 **导出链接为空、没有二维码**，通常是 **还没添加客户端**。

1. 入站展开 / 客户端列表 → **添加客户端**
2. 邮箱/备注可改成 `pc`、`phone`（随机 ID 也可）
3. 流量 / IP / 过期保持 `0` = 不限制
4. 点 **创建**

然后在该客户端行点 **二维码** 或 **导出链接**。

## 3. 导出链接注意

- 「导出链接」主要是 **复制到剪贴板**，不是可靠地下载文件
- Edge 有时会下一个 **0 字节** 的「新加坡」空文件 → 可删，以剪贴板为准
- 粘贴到记事本，应看到 `vless://...`

### 地址用 IPv6（本环境关键）

家宽 IPv4 到 VPS 不通时，链接里的 host 用：

```text
vless://UUID@[VPS_IPv6]:端口?....#备注
```

浏览器/客户端写 IPv6 都要带方括号（URL 里一般已编码）。

## 4. 节点信息自检清单

导出前确认：

- [ ] UFW / Vultr 防火墙已放行入站端口
- [ ] 传输 = RAW，安全 = Reality
- [ ] Target / SNI 一致且含 `:443`
- [ ] 已创建客户端
- [ ] 链接非空，UUID 正确
- [ ] 本机 `curl -6` 能连上该端口（可能 Empty reply，但说明端口通）

```cmd
curl.exe -6 -I --connect-timeout 5 http://[VPS_IPv6]:入站端口/
```

`Empty reply from server` = TCP 通了，但服务不是普通 HTTP（正常）。
