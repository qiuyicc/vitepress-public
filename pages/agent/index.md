# 学习 Agent

大模型本身看不到本机文件。它只能看对话、决定要不要发起工具调用；真正读磁盘的是本地代码。工具结果再写回对话，模型才能基于真实内容回答。这就是常见的 **ReAct / tool-calling Agent**：模型规划，运行时执行。
