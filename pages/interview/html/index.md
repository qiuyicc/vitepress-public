::: tip
Doctype是HTML5的⽂档声明，通过它可以告诉浏览器，使⽤哪⼀个HTML版本标准解析⽂档。如果没有事先告诉浏览器，那么浏览器就不知道⽂档解析标准是什么？此时，⼤部分浏览器将开启最⼤兼容模式来解析网页，我们⼀般称为怪异模式，不仅会降低解析效率，⽽且会在解析过中产⽣⼀些难以预知的bug，所以⽂档声明是必须的
:::

## HTML语义化

HTML标签的语义化，简单来说，就是⽤正确的标签做正确的事情，给某块内容⽤上⼀个最恰当最合适的标签，使⻚⾯有良好的结构，⻚⾯元素有含义，⽆论是谁都能看懂这块内容是什么。
优点：
1. 在没有CSS样式情况下也能够让⻚⾯呈现出清晰的结构
2. 有利于SEO和搜索引擎建⽴良好的沟通，有助于爬⾍抓取更多的有效信息，爬⾍是依赖于标签来确定上下⽂和各个关键字的权重
3. ⽅便团队开发和维护，语义化更具可读性，遵循W3C标准的团队都遵循这个标准，可以减少差异化

## 前端页面三层架构

1. 结构层：结构层类似于盖房⼦需要打地基以及房⼦的悬梁框架，它是由HTML超⽂本标记语⾔来创建的，也就是⻚⾯中的各种标签，在结构层中保存了⽤户可以看到的所有内容，⽐如说：⼀段⽂字、⼀张图⽚、⼀段视频等等
2. 表示层：CSS，层叠样式表，它是⽤于控制⻚⾯的外观和感觉的，它可以使⽤户通过⼀系列的样式来定义⻚⾯的外观，包括字体、颜色、背景、边框、布局等等，使⽤户可以更加直观的看到⻚⾯的结构
3. 行为层：JavaScript，它是⽤于控制⻚⾯的行为，使⽤户可以实现⼀系列的动态效果，包括动画、⽂件上传、表单验证、⽤户交互等等，使⽤户可以更加直观的看到⻚⾯的功能

## 严格模式与混杂模式

1. 严格模式，是以浏览器支持的最高标准运行
2. 混杂模式，页面以宽松向下兼容的方式显示，模拟老式浏览器的行为

## 行级元素和块级元素
常⻅的块级元素：p、div、form、ul、li、ol、table、h1、h2、h3、h4、h5、h6、dl、dt、dd
常⻅的⾏级元素：span、a、img、button、input、select
块级元素：
1. 总是在新行上开始，就是每个块级元素独占⼀行，默认从上到下排列
2. 宽度缺少时是它的容器的100%，除⾮设置⼀个宽
3. 高度、行高以及外边距和内边距都是可以设置的
4. 块级元素可以容纳其它行级元素和块级元素行级元素：
1. 和其它元素都会在⼀行显示
2. 行高以及外边距和内边距可以设置
3. 宽度就是⽂字或者图⽚的宽度，不能改变
4. 行级元素只能容纳⽂本或者其它⾏内元素
5. 行内元素设置宽度 width 无效
6. 行内元素设置height 无效，但是可以通过设置line-height来控制行高
7. 设置margin只有左右有效，上下无效
8. 设置padding只有左右有效，上下无效
9. 可以通过设置display属性来对行内元素和块级元素进行转换
